Proxy Server Problem

The library's proxy server cannot connect you to this resource. There could be two reasons for this:

  1. The University Library does not provide access to this resource. Try removing "https://apps.lib.umich.edu/proxy-login/?url=" from the start of the web address / URL.
  2. The University Library provides access to this resource, but we need to update the settings on the proxy server for it to work properly.

Please contact the University of Michigan Library's Ask a Librarian service to report this problem. Please provide the web address / URL or resource name you were trying to access when you got this error message.

In the meantime, you might try using Library Search to find the specific database or online journal.
